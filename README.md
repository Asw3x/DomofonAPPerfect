# Domofon App Perfect

Альтернативный неофициальный Android-клиент для домофонов, написанный на Kotlin и Jetpack Compose.

## Особенности
* Полностью переработанный UI на Jetpack Compose
* Поддержка WebRTC и SIP
* Авторизация и получение списка ключей/камер
* Настраиваемая задержка окна после открытия двери
* Корректное масштабирование видео с камер
* Своя папочная структура для удобной сортировки камер и дверей
